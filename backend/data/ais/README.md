\# AIS Data



This folder stores verified AIS vessel-track datasets used by the

Oil Spill Intelligence investigation pipeline.



\## Required fields



\- mmsi

\- timestamp

\- latitude

\- longitude

\- sog

\- cog

\- heading

\- nav\_status



\## Optional fields



\- vessel\_name

\- imo

\- vessel\_type

\- rot

\- source



\## Data requirements



1\. Timestamp must be UTC.

2\. Latitude and longitude must be valid geographic coordinates.

3\. AIS records should contain vessel movement information.

4\. Dataset source must be documented.

5\. Synthetic AIS must not be represented as real AIS.

6\. Vessel ranking must be treated as analytical suspicion, not legal guilt.
